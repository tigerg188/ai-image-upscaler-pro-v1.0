# AI 图像超分辨率与大画幅无缝缝合系统 —— 用户需求手册

## 一、 用户特征与输入习惯画像

### 1. 核心身份与场景
* **身份定位**：高阶数码图像处理专家 / 资深摄影师 / 极客极高画质追求者。
* **应用场景**：处理超大画幅摄影作品（如 4800 万像素手机照片、2400 万至数亿像素单反全景接片）、处理包含复杂高频细节（人物发丝、宠物毛发、织物纤维、皮肤微细皱纹）的图像，并输出可用于 300 DPI 印刷级或巨幅喷绘的超高清母版。

### 2. 交互与沟通习惯
* **精益求精与极限压测**：善于进行极端压力测试（如挑战 8X 放大、7.55 亿像素、2.11GB 大文件），对硬件边界（如 512MB 核显、浏览器单画布 16384px 硬件上限）有极高的敏感度。
* **拒绝虚假与AI幻觉（拒绝“AI味”）**：反对生成式 AI（如 Diffusion）带来的无中生有和画质失真。强调“忠实原画”、“用时间换空间”、“科学严谨的确定性算法”。
* **追求极致性能与离线保障**：要求 0% 依赖云端大体积上传（避免 HTTP 413 错误），所有核心计算与打包必须100% 在本地浏览器和 CPU 物理内存（24GB RAM）中流畅完成，并配有可本地独立运行的解压查看器。

---

## 二、 核心业务需求清单

1. **大画幅无损分块与“解锁”浏览**：
   * 突破浏览器单画布 16384px 硬件上限，将巨幅图像智能拆解为 2x2（4分块）田字格切片。
   * 提供前端交互式无缝平移、滚轮缩放、100% 原画点对点查看及特写截取。
2. **本地“时间换空间”流式装配引擎（0 显存崩溃）**：
   * 在集成显卡（512MB VRAM）限制下，利用 CPU 分条带（512px 扫描线）流式装配，绝不导致 UI 假死或显存溢出。
3. **亿级像素无损 PNG 导出**：
   * 抛弃传统无法被看图软件打开的 2.11GB 原始 BMP，采用流式 Deflate 压缩算法导出标准无损 PNG 巨图（~450MB，兼容所有主流 PC 看图软件）。
4. **自适应动态规格计算器**：
   * 上传图片后自动识别长宽，实时计算 2X/4X/8X 放大后的目标像素、预估体积及 300 DPI 厘米级印刷尺寸。
5. **多路线智能算法控制**：
   * 路线 A：高保真算法放大（忠实原画）。
   * 路线 B：毛细细节保持与增强（专用于发丝、宠物毛发、微细皱纹）。
   * 路线 C：AI 动态分析 + 算法执行（按需手动触发 Gemini 大模型诊断）。
6. **离线双击查看器封装（ZIP 离线包）**：
   * 一键打包 4 张超清分块及 `00_双击无缝缝合查看器.html`，可在无网或任何办公电脑上直接双击打开查看全景。
